# Pesquisa: coletor local de notificações Android

**Data:** 2026-11-16  
**Escopo:** viabilidade e limites de um coletor nativo em Kotlin/Compose, sem acesso à rede e com armazenamento privado. Fontes consultadas: documentação oficial Android.

## Resumo executivo

O caminho adequado é um `NotificationListenerService` nativo, habilitado explicitamente pelo usuário nas Configurações. Ele pode observar notificações postadas/removidas e consultar as que ainda estão ativas depois de conectado; não é um histórico geral garantido. O texto disponível varia por notificação e pode ser ocultado pelo Android. Para manter os registros no aparelho, usar armazenamento interno privado e excluir dados de backup e transferência; oferecer exportação somente por ação explícita do usuário.

## Acesso, consentimento e ciclo de vida

- Declare uma subclasse de `NotificationListenerService` no manifesto com a permissão `android.permission.BIND_NOTIFICATION_LISTENER_SERVICE`, a ação `android.service.notification.NotificationListenerService` e `android:exported="false"` — conforme o exemplo oficial. Essa permissão protege o serviço para que o sistema possa vinculá-lo; o usuário ainda precisa conceder o acesso especial nas Configurações. A ação `Settings.ACTION_NOTIFICATION_LISTENER_SETTINGS` abre a tela de listeners. [Serviço e manifesto](https://developer.android.com/reference/android/service/notification/NotificationListenerService) · [Configurações](https://developer.android.com/reference/android/provider/Settings#ACTION_NOTIFICATION_LISTENER_SETTINGS)
- Aguarde `onListenerConnected()` antes de chamar APIs do listener. A documentação apresenta `getActiveNotifications()` como consulta das notificações ativas, não como recuperação de todas as que já passaram. A partir do Android N, os callbacks são executados na thread principal; encaminhe processamento e gravação para trabalho fora dela. [NotificationListenerService](https://developer.android.com/reference/android/service/notification/NotificationListenerService)
- Um force-stop mantém o app parado até uma ação do usuário removê-lo desse estado; no Android 15, o sistema também cancela os `PendingIntent`s do app parado. Portanto, não prometa coleta durante force-stop. A documentação não garante uma política uniforme de reconexão após reboot em todos os fabricantes: validar reconexão, bateria e restrições do One UI no S23 real. [Mudanças do Android 15](https://developer.android.com/about/versions/15/behavior-changes-all#enhanced-stop-states) · [NotificationListenerService](https://developer.android.com/reference/android/service/notification/NotificationListenerService)

## Texto, grupos e sensibilidade

- Os extras podem conter `EXTRA_TITLE`, `EXTRA_TEXT`, `EXTRA_BIG_TEXT`, linhas de `InboxStyle` ou mensagens de `MessagingStyle`. Nem todos estarão presentes; trate-os como opcionais e não como representação garantida do texto mostrado na tela. [Notification](https://developer.android.com/reference/android/app/Notification#extras)
- `StatusBarNotification.isGroup()` indica participação em um grupo, não que o registro seja o resumo. Para reconhecer o resumo, verifique `Notification.FLAG_GROUP_SUMMARY`; `getGroupKey()` ajuda a relacionar itens do grupo. [StatusBarNotification](https://developer.android.com/reference/android/service/notification/StatusBarNotification) · [FLAG_GROUP_SUMMARY](https://developer.android.com/reference/android/app/Notification#FLAG_GROUP_SUMMARY)
- No Android 15, o sistema pode ocultar OTPs identificados de listeners não confiáveis. A permissão `RECEIVE_SENSITIVE_NOTIFICATIONS`, introduzida na API 36.1, tem proteção `signature|preinstalled|knownSigner|role`; um app comum não deve presumir que pode obtê-la. Isso não significa que todo app bancário esconda todo o conteúdo. [Mudanças do Android 15](https://developer.android.com/about/versions/15/behavior-changes-all#otp-redaction) · [Permissão](https://developer.android.com/reference/android/Manifest.permission#RECEIVE_SENSITIVE_NOTIFICATIONS)
- Para um coletor de diagnóstico, minimize desde a captura: guardar apenas campos necessários, evitar logs de conteúdo integral e permitir apagar registros. Isso reduz exposição, mas não supera redações aplicadas pelo sistema ou pelo app que publicou a notificação.

## Android 16/17 e ferramentas

- A tabela oficial associa Android 16 à API 36 e Android 17 à API 37. A página de configuração do Android 17 ainda instrui instalar o pacote **Cinnamon Bun Preview**; confirme a disponibilidade local do SDK antes de escolhê-lo. Como base conservadora, API 36 é a opção estável documentada; adotar API 37 exige validar SDK, IDE e plugins compatíveis. [Níveis de API](https://developer.android.com/guide/topics/manifest/uses-sdk-element#ApiLevels) · [Setup do Android 17](https://developer.android.com/about/versions/17/setup-sdk)
- A documentação do AGP 9.5 declara suporte até API 37, Gradle 9.6 e JDK 17. Para Compose, o plugin Gradle do compilador Compose está disponível com Kotlin 2.0 ou superior e sua versão deve acompanhar a versão Kotlin. Verifique compatibilidade entre versões escolhidas e SDK instalado, em vez de fixar versões com base apenas no número da API. [Compatibilidade do AGP](https://developer.android.com/build/releases/gradle-plugin) · [Plugin do compilador Compose](https://developer.android.com/develop/ui/compose/compiler)
- Para o conjunto local escolhido, a página específica do AGP 9.0.1 confirma Gradle 9.1.0, build-tools 36.0.0, JDK mínimo 17, suporte até API 36.1 e Kotlin integrado 2.2.10. Assim, manter API 36 e plugin Compose 2.2.10 sem aplicar `org.jetbrains.kotlin.android`. O launcher Gradle 9.1.0 foi executado com o JDK 21 local; o build do projeto ainda deve validar dependências transitivas. [AGP 9.0](https://developer.android.com/build/releases/agp-9-0-0-release-notes)
- “Galaxy S23 com Android 17” é a informação fornecida pelo usuário; não foi verificada neste levantamento no aparelho. Confirme a versão instalada em **Configurações > Sobre o telefone > Informações do software** antes de fechar a configuração de teste.

## Armazenamento, exportação e rede

- O armazenamento interno específico do app não exige permissão de armazenamento e não é acessível por outros apps; é o local indicado para os registros locais. [Armazenamento específico do app](https://developer.android.com/training/data-storage/app-specific)
- Para exportar, `ACTION_CREATE_DOCUMENT` abre o seletor do sistema e concede acesso ao URI escolhido, sem permissão geral de armazenamento. O seletor pode oferecer provedores locais ou em nuvem: selecionar um provedor cloud pode transferir o arquivo para fora do aparelho, mesmo sem o coletor declarar `INTERNET`. O uso de `INTERNET` é o que permite ao app abrir sockets de rede; não controla a rede de outro provedor escolhido pelo usuário. [Storage Access Framework](https://developer.android.com/training/data-storage/shared/documents-files) · [Permissão INTERNET](https://developer.android.com/reference/android/Manifest.permission#INTERNET)
- O Auto Backup inclui por padrão bancos de dados e arquivos internos. `android:allowBackup="false"` desativa backup em nuvem, mas alguns fabricantes ainda permitem transferência aparelho-a-aparelho para apps que miram API 31+. Para uma exigência estrita de permanência local, configure exclusões para `cloud-backup` e `device-transfer` via `dataExtractionRules`; mantenha também as regras legadas de `fullBackupContent` para Android 11 e anteriores, se suportados. [Auto Backup e regras](https://developer.android.com/identity/data/autobackup) · [Atributo allowBackup](https://developer.android.com/guide/topics/manifest/application-element#allowbackup)

## Plano de validação no aparelho

Antes de depender do coletor, testar com notificações não sensíveis: concessão/revogação do acesso, captura expandida e recolhida, atualização da mesma notificação, agrupamento/resumo, encerramento e reinício do app, reboot, force-stop e exportação com provedor local. Depois, conferir em separado a disponibilidade real dos avisos relevantes; a API não garante conteúdo integral nem entrega sem falhas. Não usar credenciais bancárias ou automação do app do banco para validar o mecanismo.
